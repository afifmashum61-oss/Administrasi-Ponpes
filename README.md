# 🌿 Administrasi-Ponpes: Sistem Pengelolaan Keuangan & Kegiatan Pondok Pesantren

Aplikasi web modern, responsif, dan interaktif untuk tata kelola administrasi keuangan dan agenda kegiatan pondok pesantren. Didesain dengan estetika *Deep Emerald / Forest Green* fintech premium dengan dukungan simulasi mobile mockup dan dashboard komputer.

---

## ✨ Fitur Utama

### 1. 💰 Manajemen Keuangan Pesantren (Cashflow)
- **SPP Bulanan Santri**: Pencatatan kas masuk syahriah santri secara terorganisir.
- **Konsumsi Dapur**: Belanja bahan makanan harian santri (dapur umum 350+ santri).
- **Bisyarah Guru / Asatidz**: Honorarium dan tunjangan asatidz pengajar kitab kuning & tahfidz.
- **Pengeluaran untuk Pembangunan**: Pembelian semen, pasir, dan material renovasi asrama/gedung pesantren.
- **Kartu Saldo Interaktif**: Menampilkan saldo kas pondok, fitur intip saldo (sembunyikan/tampilkan nominal), dan tren pertumbuhan infaq.

### 2. 📅 Manajemen Kegiatan Santri (Agenda & Anggaran)
- Jadwal kajian kitab kuning, PHBI, tasmi' tahfidz, ro'an kebersihan, dan imtihan.
- Pelacakan **Pagu Anggaran vs Realisasi Biaya** per kegiatan secara real-time.
- Pencatatan penanggung jawab (PJ) ustadz / mudabbir santri dan lokasi kegiatan.

### 3. 📊 Analisis & Evaluasi Anggaran
- **Donut Chart**: Visualisasi persentase pengeluaran berdasarkan pos kategori.
- **Indikator Kepatuhan Anggaran**: Notifikasi evaluasi pagu belanja pondok.
- **Grafik Tren Bulanan**: Perbandingan pengeluaran per bulan.

### 4. 🖨️ Laporan Siap Cetak (Print / PDF)
- Laporan resmi pertanggungjawaban kas dengan kop lembaga pondok pesantren.

### 5. 📱 3 Mode Tampilan Fleksibel
- **Mockup 3 Layar (Sesuai Desain)**: Tiga frame smartphone berdampingan (Onboarding, Beranda, Analisis).
- **HP Interaktif**: Simulator smartphone interaktif untuk alur mobile.
- **Dashboard Komputer**: Tampilan widescreen penuh untuk admin/bendahara di PC/laptop.

## 🚀 Panduan Memulai (Instalasi & Menjalankan)

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18+)
- [Git](https://git-scm.com/)

### Langkah Menjalankan:
```bash
# 1. Clone repository ini
git clone https://github.com/afifmashum61-oss/Administrasi-Ponpes.git

# 2. Masuk ke direktori proyek
cd Administrasi-Ponpes

# 3. Install dependensi
npm install

# 4. Jalankan server lokal
npm run dev
```

Buka browser Anda di `http://localhost:5173/`.
